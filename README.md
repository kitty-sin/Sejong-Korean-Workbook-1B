## 🎯 系統架構與設計特色

1. **原版 102 頁翻頁閱讀器 (Reader Engine)**：
   - 滿版展開（鎖定 `589 / 807` 原書長寬比），自然垂直雙向滑動。
   - 34px 翻頁箭頭貼邊固定。
   - 底部 52px 微縮膠捲抽屜。
   - 換頁時自動平滑回頂回左。
2. **聽力專屬點讀熱區 (Listening Hotspots)**：
   - 嚴格遵守練習冊規範，畫面保持乾淨書寫格，不混入課本單字/句型熱區。
   - 12 單元聽力頁面（第 11, 17, 23, 29, 35, 41, 47, 53, 59, 65, 71, 77 頁）全量對齊 60 個官方聽力題號。
   - 藍莓香芋紫光暈與 `🎧` 耳機圖示。
3. **KittyVoice 四級高可用發音引擎**：
   - 點擊聽力題號直接播放官方 MP3 原音檔 (`playAudioFile`)。
   - 支援 `0.3x`、`0.7x`、`1.0x` 三段速變速播放。
4. **Firebase Hosting 多站點隔離**：
   - 部署至專屬獨立站點 `sejong-workbook-1b-1ec2a`，杜絕覆蓋預設主站。
